# Price-Tag-Pick-Lab
Interactive psychology demos: pricing (anchoring, decoy effect, loss aversion) and hiring (halo effect, structured selection). Simulated data, built for my MSc Business Psychology portfolio.

Price Tag & Pick Lab is a single-page simulator. You set a café's subscription prices and watch 100 simulated shoppers choose, then hire a barista by gut feel and again by scorecard. The results screen explains which psychological effects moved the outcome.

Theories: anchoring, decoy effect, loss aversion, halo effect, structured selection.
Note: all shoppers and candidates are simulated, and the effect sizes are illustrative, not research findings.
Built with plain HTML, CSS and JavaScript. No data is collected.
